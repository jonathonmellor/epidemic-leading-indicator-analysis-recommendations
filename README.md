# Recommendations for the Analysis of Leading Indicators in Epidemic Surveillance
Repository containing simulation code supporting the article ["Recommendations for the Analysis of Leading Indicators in Epidemic Surveillance"](https://journals.plos.org/digitalhealth/article?id=10.1371/journal.pdig.0001759) published in PLOS Digital Health. DOI: 10.1371/journal.pdig.0001759

# Contents

The code contains two main scripts `figures.R` and `maps.R` containing code to produce their namesakes. 

The manuscript is available in `manuscript.pdf`.

Figures are produced by simulation of a deterministic SEIR age stratified model, with downstream transformations on incidence.
